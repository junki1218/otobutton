> **2026-11-05 完了。16点すべて生成し、`assets/icons/` に置いた。**
> 作り方: Canva の画像生成 → 背景除去 → 余白を切り詰めて正方形の透過PNGに統一。
> `cymbal` だけ1回目が「金の皿1枚」に見えたので作り直した（2枚が分かる形に）。

> ### 原本（1024）と、アプリに入れるぶん（512）を分けている
>
> **原本は 1024×1024（`ui_logo` だけ 1024×512）。素材ライブラリに置いた（2026-11-05・16点）。**
>
> ```
> G:\マイドライブ\04_素材ライブラリ\画像材料\ClayAnimation\おとボタン\
> ```
>
> **作り直すとき・別の教材で使うときは、この原本を使う。**
>
> **アプリの `assets/icons/` には 512×512 を置く**（`ui_logo` は 512×256）。
> 画面に出る一番大きい姿が170px前後なので、画面の密度が2倍の端末でも512で足りる。
> 1024のままだと16点で13.3MB、512にして2.7MB。
>
> 縮め直すときは、**必ず原本から**（縮めたものを縮め直さない）。
> `tools/shrink_icons.py` が原本を読んで `assets/icons/` に書く。
>
> ```bash
> python tools/shrink_icons.py
> ```
>
> ### 手元で見るときのサーバ
>
> `python -m http.server` は HTTP/1.0 で1件ずつしかさばけず、
> **画像が途中で切れて届くこと**があった（Content-Length は正しいのに末尾が欠け、
> ブラウザが「壊れた画像」と見なす）。計測では64回中6回。
> `tools/serve.py`（HTTP/1.1・同時にさばく）に替えて 64回中0回になった。
> **画像が出たり出なかったりしたら、まずサーバを疑う。** 画像の大きさの問題ではない。

## 共通の仕様

| 項目 | 指定 |
|---|---|
| タッチ | 3Dクレイアニメーション（`claymation_style_guide.md` に準拠） |
| 画像サイズ | 1024 × 1024（正方形）。**アプリに入れるときは512に縮める**（上の注記） |
| 背景 | **透過（アルファ付き PNG）**。透過で出せない場合は**真っ白な背景**で生成し、`process_image.py` で抜く |
| 構図 | 対象を**1つだけ**、画面中央。上下左右に 10% の余白をとる（ボタンに収まるように） |
| 向き | ななめ正面（真上や真横は避ける）。立体感が出る角度 |
| 文字 | **絵の中に文字・数字・記号を入れない**（名前はアプリ側がひらがなで出す） |
| 人物 | **入れない**。道具・物だけ（ロゴとわらいごえの顔を除く） |
| 影 | 柔らかい影。接地影は薄く、または無し（透過で切り抜くため） |
| 色 | 鮮やかで明るい。ボタンの色（赤・青・黄など10色）の上に載るので、**白や灰色一色にしない** |
| 保存先 | `OtoButton/assets/icons/` にファイル名のとおりに置く |

### 粒（`clay_grain.png`）の作り方

```python
from PIL import Image
src = Image.open("assets/ui/clay_texture.png").convert("L")
grain = Image.new("RGBA", src.size)
sp, gp = src.load(), grain.load()
for y in range(src.height):
    for x in range(src.width):
        a = max(0, min(90, int((250 - sp[x, y]) * 1.6)))
        gp[x, y] = (72, 54, 38, a)
grain.resize((300, 300), Image.LANCZOS).save("assets/ui/clay_grain.png")
```

**合成モード（`mix-blend-mode`）やマスクは使わない。** 端末によって出ず、
出なかったときにボタンが真っ白になる。粒を普通に重ねるだけにする。
