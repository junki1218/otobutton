# おとボタン

ボタンを押すと音が鳴る、タブレット用のアプリ。複数同時に鳴らせる。
**鳴っている最中にもう一度押すと、はじめから鳴り直す**（ボタンごとに
「いちじていし」にも変えられる）。

**→ https://junki1218.github.io/otobutton/**
（タブレットでこれを開き、ホーム画面に追加して使う）

- 仕様 → [SPEC.md](SPEC.md)
- 作りの方針 → [PLAN.md](PLAN.md)
- 足りない絵の生成指示 → [docs/画像生成指示書.md](docs/画像生成指示書.md)
- 同梱した音の出典 → [sounds/CREDITS.md](sounds/CREDITS.md)

## 使い方

### PC で試す

このフォルダで

```
python tools/serve.py
```

を走らせ、ブラウザで `http://localhost:8123` を開く。

**ファイルを直接ダブルクリックしても、音の一覧が読めず正しく動かない**（ブラウザの制限）。
かならずサーバ越しに開くこと。

**`python -m http.server` は使わない。** 画像が途中で切れて届くことがあり
（64回中6回）、絵が出たり出なかったりする。`tools/serve.py` では 64回中0回。

### タブレットで使う（公開ずみ）

**https://junki1218.github.io/otobutton/** をタブレットで開き、
Safari の共有ボタンから**ホーム画面に追加**する。
ホーム画面から開くと、アドレスバーが消えて画面を広く使える。
**入れた音が消えにくくなるので、ホーム画面から使うことをすすめる。**

### 直したものを公開に反映する

公開先は GitHub の `junki1218/otobutton`（`main` ブランチの `/`）。
手元で直したら、

```
git add -A && git commit -m "なにを直したか" && git push
```

1〜2分でサイトに反映される。

**このリポジトリは公開。** `sounds/` に自分の音楽を入れて push すると、
その曲も誰でも聴ける状態になる。**権利を確かめてから上げること**
（詳しくは [sounds/CREDITS.md](sounds/CREDITS.md)）。
授業で使うだけの音なら、push せず **アプリの「ファイルから」で端末に入れる**ほうが安全。

## iPad で録った声をボタンに入れる

**PC は要らない。タブレットだけでできる。**

1. iPad の「ボイスメモ」などで録り、**「ファイル」アプリに保存**する
2. おとボタンの設定画面を開く（暗証番号 4桁。最初は `0000`）
3. 入れたいボタンの「おと」の行にある **「ファイルから」** を押す
4. 「ファイル」や「ミュージック」が開くので、録った音を選ぶ

選んだ音はすぐそのボタンに入り、一覧（「いれた おと」）にも並ぶ。
**一度入れた音は、別のボタンにも「おと」の一覧から選べる。**

入れた音は設定画面の「この きかいに いれた おと」で確かめられ、
「きく」で試聴、「けす」で消せる。使っているボタンがあれば、
消す前に何個で使っているかを教える。

**どこに入るか。** その端末のブラウザの中（IndexedDB）。
**別の端末には自動では行かない。** 運ぶときは下の「設定を別の端末へ渡す」を使う。
1ファイル 30MB まで。

**消えることがある。** iOS はしばらく開いていないサイトのデータを消すことがある。
ホーム画面に追加して使えば残りやすいはずだが、**これは実機で確かめていない。**
大事な音は「かきだす」で手元に持っておくこと。

## 自分の音楽を足す（PC から・まとめて入れるとき）

たくさんの曲を入れるならこちら。

1. `sounds/` フォルダに mp3 / m4a / wav を入れる
2. 下を走らせる（**これを忘れると設定画面に出てこない**）

```
python tools/refresh_sounds.py
```

3. アプリの設定画面 →「おと」の一覧に「じぶんの おんがく」として出てくる

ブラウザはフォルダの中身を自分で見られないので、この一覧づくりが要る。

## おしなおしたときの動きを変える

設定画面のボタンごとに **「おしなおすと」** の行がある。

| えらぶもの | 動き | 向いているもの |
|---|---|---|
| **はじめから**（最初はこちら） | 頭に戻って鳴り直す | 太鼓・クラッカーなど、押すたびに鳴ってほしい音 |
| いちじていし | その場で止まり、次に押すと続きから | 長い曲・読み聞かせの音声 |

**「はじめから」のボタンは、そのボタンでは止められない。**
止めたいときは「ぜんぶとめる」を押す。長い音を入れるなら「いちじていし」にする。

押してから 0.35 秒は次の反応を受け付けない（手がふるえて二重に入るのを防ぐため）。
続けて鳴らしたいときは、少し間をあけて押す。

## 設定画面に入るには

スタート画面の「せってい」、またはメイン画面の「せってい」を押し、
**暗証番号 4桁**（最初は `0000`）を入れる。番号は設定画面で変えられる。

## 設定を別の端末へ渡す

設定画面 →「せっていの もちだし」→「かきだす」で JSON ファイルが落ちる。
渡したい端末で同じ画面の「よみこむ」から読ませる。

**「ファイルから」で入れた音も、この JSON に一緒に入る**（使っているものだけ）。
別の端末で読み込めば音ごと復元される。音を入れていなければ中身はこれまでと同じ。
音が入るぶんファイルは大きくなる（1分の録音でおよそ1MB）。

## 見た目

画面はぜんぶクレイアニメーション調。ボタンの絵（`assets/icons/`）だけでなく、
**ボタンの土台・ボタンを並べる台・下の操作列・設定の板**も粘土の素材（`assets/ui/`）で作ってある。

ボタンの色を増やしたいときは `js/store.js` の `COLORS` に色を足すだけでよい
（粘土の質感は共通の `clay_grain.png` が受け持つので、色ごとの画像は要らない）。

## 絵について

`assets/icons/` にクレイアニメ調の絵が16点入っている（2026-11-05 作成）。
ボタン用12点と画面部品4点。作り方と指示文は [docs/画像生成指示書.md](docs/画像生成指示書.md)。

**原本（1024×1024）は素材ライブラリにある。**

```
G:\マイドライブ\04_素材ライブラリ\画像材料\ClayAnimation\おとボタン\
```

**アプリに入っているのは、そこから 512×512 に縮めたもの**（合計2.7MB）。
原本をそのまま入れると13.3MBになり、読み込みが重い。縮め直すときは

```
python tools/shrink_icons.py
```

を走らせる（原本から作り直す。縮めたものを縮め直さない）。

絵を差し替えるときは、原本を素材ライブラリに置いてから上のコマンドを走らせる。
**ファイルが無くてもアプリは動く**（絵の場所は自動で隠れ、ひらがなの名前だけで使える）。
